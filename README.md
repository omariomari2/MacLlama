# MacLlama

A macOS menu bar client for chatting with locally hosted Ollama models.
This repository is based on [MyMacLLAMA by carlosmbe](https://github.com/carlosmbe/MyMacLLAMA).

## Run locally

1. Use macOS 14.2 or later and Xcode.
2. Install Ollama and download a model.
3. Start Ollama with `ollama serve`.
4. Open `MacLlama.xcodeproj` and select your signing team.
5. Build and run the app.

Select a model, enter a prompt, and send it from the menu bar window.
The interface includes a streaming response option.

## Scope

A learning copy of a local model client. This README does not claim authorship of the upstream application.
Model availability and speed depend on the local Ollama installation and hardware.
